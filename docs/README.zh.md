# MarcbasePro

> [English](/README.md) / **简体中文**

MarcbasePro 是一款自由的，适用于我国高中教学的屏幕书写软件。

MarcbasePro 受到 [希沃白板](https://easinote.seewo.com) 的启发, 并希望解决其 **强制登录**、**冗杂不必要功能** 的问题, 并针对一些场景, 设计了信的书写体验逻辑。

## 技术栈和组件

MarcbasePro 使用 [TurboWarp](https://turbowarp.org) 制作。相关用到的 JavaScript 扩展借助了 `ChatGPT 5.6 Sol` 的帮助。

MarcbasePro 需要 **打包** 运行。

## 打包使用

如果可以连接互联网, 请使用 [Packager](https://packager.turbowarp.org)。或者您安装了[桌面 TurboWarp 编辑器](https://desktop.turbowarp.org), 请使用桌面编辑器的 `文件` > `打包作品`。

确保您保持了以下设置:

| 设置 | 数值 |
| --- | --- |
| 自定义帧率 | 60 |
| 高清画笔 | 是 |
| 无限克隆 | 是 |
| 角色可穿过边缘 | 是 |
| 移除其他限制 | 是 |
| 作品停止时自动关闭窗口 | 是 |
| 自定义舞台大小 | 960x540 |
| 在加载时自动运行而不是显示一个大绿旗 | 是 |

然后选择打包为适用于您平台的 `Electron` 应用。

您也可以到我们的 Release 页面下载我们打包好的压缩包。

## 计划实现的功能

- **无限画布**: 无需想希沃那样点击板中板来获得无限画布。
- **撤销和重做**: 记录笔迹过程。
- **看着更舒服的 UI**: 稍稍好看一丢丢的流畅的界面动画。
- **插入直角坐标系工作台**: 支持:
  - **平面直角坐标系** 的插入和编辑展示等。
  - **空间直角坐标系** 的插入和编辑展示等。允许您创建立体图形和向量等。
- **元素周期表为基础的键盘**: 快速插入表达式。

未来可能会添加更多计划功能。
